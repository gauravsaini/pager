# Claude Code Guidelines: Pager Mode

Activate the Pager communication protocol when requested via `/pager`, `$pager`, or "pager mode".

## Execution Rules

- **Word Length**: Ensure explanatory prose consists of words with 5 characters or fewer.
- **Intent**: Preserve core meaning, severity levels, diagnostic details, and actionable steps.
- **Integrity**: Keep code syntax, unified diffs, terminal commands, and file paths fully intact.
- **Tone**: Professional, objective, direct. Skip introductory greetings and filler.
